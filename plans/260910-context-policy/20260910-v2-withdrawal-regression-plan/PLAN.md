# Paired withdrawal representation regression

The user continuation authorizes implementation and one small bounded regression
probe. Preserve every prior dataset, reference, capture and score. No training,
external evaluation, paid judge or automatic GPU retry. Freeze all sources and
inputs before launch. One H100 function, 900-second timeout, internal stop at
850 seconds, zero retries; stop on any of 40 failed actual-reader cache fixtures.

## One controlled representation comparison

Both arms use the same new answer-only system instruction and runner-supplied
archive message, the same FP32 math-SDPA/TF32-off base model and token budgets.
They differ only in the rendering of annotated user withdrawals. Raw shows the
original withdrawal text. Neutral shows a topic and `UNKNOWN` at that source
turn, with the original role/turn label. The common instruction says that later
explicit user statements may establish a new value, while assistant suggestions
and fictional passages may not. Neither unknown nor withdrawal implies dislike.

Topic labels are manually authored, source-hash-bound annotations for ten
selected real-development withdrawals and six synthetic-fixture withdrawals.
They are not a general withdrawal classifier or a learned memory mechanism.
Only those annotated turns are normalized. Other ledger entries and all earlier
quotations remain unchanged, so this is not deletion of raw archival values.
Topics are fixed per history independently of which query is run. Private
reference answers do not enter the reader image, normalization or retrieval.

Use identical BM25 ranking and source chunk IDs in both arms. Normalize mapped
withdrawal turns in notes, recent text and selected evidence after retrieval.
Check the unchanged 768/512/1024 token budgets for both views; never silently
drop a quote or clip a neutral record to fit. Fail preparation on budget excess
or a clipped withdrawal that cannot be transformed with its role/turn binding.

## Cases and collection

Twenty-one questions produce 42 captures, one per arm. The ten earlier
withdrawal questions use one retrieval, where all failed the preceding run.
Two further unchanged questions test retained rehearsal facts and the prior
wrong-passage error, also with one retrieval. An unchanged missing-price question
uses zero retrieval to exercise the observed trailing-action-marker failure.

Eight new, hand-authored source fixtures test a later different preference, a
later same preference, assistant inability to restore withdrawn facts, unrelated
topic preservation, a named fictional character, a draft that does not establish
biography, a later factual update and passage attribution. They are development
fixtures, not natural-dialogue or independently held-out evidence. Their full
sources are short enough to be visible. Both arms get one retrieval.

Alternate arm order by the frozen question index. Each capture starts from a
fresh cache; output cap is 192 tokens, and the supplied ANSWER prefix remains
explicit. No actual retrieval decisions or generated action-format success are
claimed. Validate bodies with EOS, nonempty text, no reserved action marker
anywhere and at most 90 whitespace-delimited words. Keep the legacy capture
helper for historical replay; apply the corrected validator on the new path.

## Frozen review and decision

Require task completeness, source consistency, visible-state support, body
validity and word-limit compliance together. For unknown-value cases, recognize
uncertainty or ask for a current value without repeating the withdrawn value,
inferring its opposite or claiming neither option is preferred. A later explicit
user restatement must be usable; blanketing every topic as unknown fails the
positive controls. Draft recall must stay with its specified original source and
owner. Correct acknowledgments of unavailable price information are acceptable.

The same Codex author reviews against frozen source-bound references. Bind every
judgment to its actual capture and reference. Report raw and neutral counts by
case type, their paired differences, and all failures. A clean local regression
requires all 21 neutral-arm cases to pass, including the positive controls; any
failure remains a development blocker. Passing this selected fixture still does
not admit the full corpus or establish generalization or learned forgetting.
Comparison to the preceding run changes the prompt and protocol as well, so only
the paired arms isolate this annotated representation difference.

Verify the 40 exact cache fixtures, all source snapshots and input hashes, actual
views against the CPU replay, generated tokens, final app status and measured
billing. Record the outcome and stop; freeze a separate revision before any
further intervention or paid run.
